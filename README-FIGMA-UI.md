# Bharat Bachat — Figma UI Production Pass

This build applies the Bharat Bachat Figma visual system to the existing production frontend.

## Preserved
- Existing API contracts and backend
- Authentication / JWT / RBAC
- Existing routes and navigation logic
- Accounting and loan business rules
- Hindi/English i18n behavior
- PWA assets/configuration
- Existing PDF/share flows

## UI work
- Figma-style navy application header
- Group context and role indicator
- Inter/Poppins typography system
- Emerald vault/hero treatment
- Banking-style metric cards
- Financial ledger/passbook styling
- Loan tracker cards and progress states
- Member/profile cards
- Admin/settings form system
- Modal, button, field and status badge system
- Responsive mobile layout and bottom navigation
- Pixel-safe spacing, font sizing and tabular currency alignment

A full production build could not be completed in this offline working container because the dependency tree was not fully available; source changes were checked for file-level integrity.
