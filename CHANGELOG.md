# Changelog

## Backend performance remediation

- Optimized Save All Kist member/share reads using request-scoped batch loading.
- Moved duplicate-share and ownership validation ahead of financial writes.
- Replaced per-share historical transaction materialization (up to 500 rows) with MongoDB aggregation in integer minor units.
- Acquired share locks in deterministic order before posting and ensured acquired locks are released in `finally`.
- Added slow Save All Kist phase timing logs without logging payment details or member IDs.
- Scoped Save All Kist status aggregation to the currently requested member page.
- Added audit and test-status documentation.

No frontend source or API response schema was intentionally changed. No financial collections or historical records were deleted or migrated.

## 2026-10-18 — Save All Kist latency and notification reduction

- `_finalize_tx_side_effects` now runs the idempotent journal posting, financial-feed upsert, and audit write concurrently. The source transaction is already durable before this step; failed effects remain retryable through the existing side-effect recovery path.
- The bulk monthly-kist path reuses its earlier member/share ownership validation instead of repeating relation lookups for each allocation.
- Save All Kist suppresses per-transaction member/admin notifications for both kist transactions and BC penalties generated by that bulk operation.
- The bulk operation dismisses existing per-transaction kist/BC-penalty notifications for the selected month and upserts one admin summary notification per tenant/month.
- Slow request logging now includes time spent acquiring locks, in addition to total, posting, and penalty durations.
- Validation: Python compile/AST syntax checks pass. Automated pytest collection could not run because required packages (including `bson`/PyMongo) are absent and package installation is blocked by unavailable network access. No live MongoDB/staging benchmark was available, so production latency improvement still needs measurement.
